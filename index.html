Assumptions, rules and reproducibility

Eight binary coordinates, 256 equally weighted residual worlds. The reference affine class has 16 members. Every candidate class member must match all acquired bits; only an empty compatible class warrants rejection. This guided run starts with a deliberately chosen inadequate world (bit 0 = 1; all others = 0). New-world mode samples uniformly from inadequate worlds. Coverage bars enumerate all feasible observation sets; best fixed-set rejection is not the same as existential witness coverage. All configurations used here are derivable from the public eight-probe fixture, not a new study. No real AI inference, hidden private evaluation data, telemetry or production authorization is involved.
